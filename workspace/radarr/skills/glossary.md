# Glossary (skill file — code/internal term → product language)

| Internal / code term | Product term to use | Notes |
|---|---|---|
| root folder | root folder | Already user-facing in the UI; means "the disk location where movie folders are created" |
| quality profile | quality profile | User-facing; the rules for which file qualities are acceptable and which to upgrade to |
| minimum availability | minimum availability | User-facing; when Radarr should start considering a movie downloadable (announced / in cinemas / released) |
| grab | grab | User-facing (History shows "Grabbed"); means "a release was chosen and sent to the download client" |
| indexer | indexer | User-facing; a search source Radarr queries for downloadable releases |
| download client | download client | User-facing; the external program that performs the actual download |
| RSS sync | RSS sync | User-facing task name; the periodic (default 30 min) check of indexer feeds for new releases |
| import | import | User-facing; moving/renaming a completed download into the movie's library folder |
